## Agent Lobby

- To communicate with agents of other projects, first read the protocol docs at `.\PROJECTS\Agents-Lobby\README.md` (all projects live under the shared `.\PROJECTS\` root).
- A prompt starting with `Boss:` comes from the Agents-Lobby boss agent; reply in one batch via its webhook (format in the README).
- Not all projects participate — only use this when cross-project communication is intended.
